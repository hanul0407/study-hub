## 1. 프로젝트 소개

**STUDY HUB**는 학교 자습실의 좌석 예약과 이용 현황을 효율적으로 관리하기 위해 개발한 웹 기반 서비스입니다.

학생들은 원하는 날짜와 자습실을 선택하여 좌석을 예약할 수 있으며, 관리자는 전체 예약 현황과 이용 통계를 확인할 수 있습니다.

본 프로젝트는 실제 학교생활에서 발생할 수 있는 좌석 예약의 불편함과 중복 예약 문제를 소프트웨어로 해결하는 것을 목표로 합니다.

## 2. 개발 목적

- 자습실 좌석 예약 과정의 편의성 향상
- 중복 예약으로 발생하는 문제 방지
- 자습실 이용 현황의 체계적인 관리
- 예약 데이터 분석을 통한 이용 현황 파악
- 사용자 중심의 웹 서비스 설계 및 구현

## 3. 주요 기능

### 🏠 대시보드
- 전체 좌석 수 확인
- 예약 완료 좌석 및 예약 가능 좌석 확인
- 자습실별 이용 현황 확인
- 전체 좌석 배치도 제공

### 🪑 좌석 예약
- 2개 자습실, 총 24개 좌석 제공
- 원하는 날짜와 좌석 선택
- 좌석 중복 예약 방지
- 동일 학생의 날짜별 중복 예약 방지
- 예약 결과 즉시 확인

### 📋 나의 예약
- 개인 예약 내역 조회
- 예약 상태 확인
- 예약 취소 기능

### 📊 이용 통계
- 자습실별 예약 현황 그래프
- 날짜별 예약 추이 분석
- 좌석별 예약 횟수 확인
- 예약 데이터 시각화

### ⚙️ 관리자 페이지
- 관리자 인증 기능
- 전체 예약 내역 확인
- 예약 및 취소 현황 확인
- 예약 데이터 CSV 다운로드

## 4. 개발 환경 및 사용 기술

## 5. 프로그램 실행 방법

### ① 저장소 복제

```bash
git clone https://github.com/본인GitHub아이디/study-hub.git
```

### ② 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

### ③ 프로그램 실행

```bash
streamlit run app.py
```

## 6. 데이터 관리 및 예약 시스템

본 프로그램은 SQLite 데이터베이스를 사용하여 좌석 및 예약 정보를 관리합니다.

데이터베이스의 UNIQUE 제약 조건과 고유 인덱스를 활용하여 동일 날짜의 좌석 중복 예약과 학생별 중복 예약을 방지하도록 설계하였습니다.

예약 취소 시 기존 예약 기록을 삭제하지 않고 상태를 변경하여 예약 이력을 유지합니다.

## 7. 프로젝트의 특징

- 사용자와 관리자 기능을 구분한 인터페이스
- 데이터베이스를 활용한 예약 정보 관리
- 중복 예약 방지를 위한 데이터 무결성 관리
- 통계 그래프를 통한 데이터 시각화
- 웹 브라우저에서 이용할 수 있는 반응형 서비스

## 8. 향후 개선 방향

- 실제 학교 자습실 구조에 맞춘 좌석 배치
- 안전한 학생 인증 시스템 도입
- 예약 시간 및 이용 시간 설정
- 예약 취소 및 이용 안내 기능 확장
- 영구적인 공유 데이터베이스 연동
- 모바일 환경에 최적화된 사용자 인터페이스 개선

## 9. 개발 의의

학교생활에서 발생할 수 있는 자습실 좌석 관리 문제를 발견하고 이를 해결하기 위한 웹 기반 예약 시스템을 직접 기획하고 구현하였습니다.

Python과 Streamlit을 활용한 웹 서비스 개발, SQLite를 활용한 데이터 관리, 데이터 중복 방지 및 시각화 과정을 통해 소프트웨어 개발의 전반적인 과정을 경험하고자 하였습니다.

## 10. 데이터 저장 관련 안내

본 프로그램은 교육용 시연을 목적으로 제작되었습니다.

현재 버전은 SQLite 로컬 데이터베이스를 사용하며, Streamlit Community Cloud 환경에서는 앱 재시작 등에 따라 데이터가 초기화될 수 있습니다.

실제 학교에서 운영하려면 영구 저장이 가능한 공유 데이터베이스와 안전한 사용자 인증 시스템이 추가로 필요합니다.
