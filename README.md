
# 📚 STUDY HUB

### 스마트 자습실 좌석 예약 시스템

STUDY HUB는 학생들이 온라인으로 자습실의 잔여 좌석을 확인하고 원하는 날짜와 시간에 좌석을 예약할 수 있도록 개발한 웹 기반 자습실 예약 프로그램입니다.

## 1. 프로젝트 소개

학교 자습실의 좌석을 효율적으로 관리하고 학생들의 편리한 좌석 예약을 지원하기 위해 제작했습니다.

## 2. 주요 기능

- 이름과 학번을 통한 사용자 구분
- 날짜별 좌석 예약
- 시간대별 좌석 예약
- 자습실별 좌석 배치도
- 실시간 예약 현황 확인
- 중복 좌석 예약 방지
- 개인별 예약 내역 조회
- 예약 취소
- 관리자 예약 현황 조회

## 3. 자습실 구성

| 위치 | 자습실 | 좌석 수 |
|---|---|---:|
| 3층 | A실 | 30석 |
| 3층 | B실 | 30석 |
| 4층 | C실 | 60석 |
| 합계 | 3개 | 120석 |

## 4. 사용 기술

- Python
- Streamlit
- SQLite
- GitHub
- Streamlit Community Cloud

## 5. 실행 방법

필요한 라이브러리 설치:

```bash
pip install -r requirements.txt
```

프로그램 실행:

```bash
streamlit run app.py
```

## 6. 예약 운영 방식

- 날짜와 시간대를 선택합니다.
- 원하는 자습실을 선택합니다.
- 예약 가능한 좌석을 선택합니다.
- 예약 확정 버튼을 누릅니다.
- 내 예약 메뉴에서 예약 내역을 확인할 수 있습니다.

## 7. 데이터 관리 및 유의사항

SQLite를 사용하여 예약 정보를 관리합니다.

현재 기본 구성은 시연용이며, Streamlit Cloud의 로컬 파일은 재시작이나 재배포 후 유지가 보장되지 않습니다. 지속적인 온라인 운영을 위해서는 외부 데이터베이스 연결이 필요합니다.

또한 기본 로그인은 실제 계정 인증이 아니므로 실제 학생 개인정보를 사용하기 전 별도의 보안 및 개인정보 보호 검토가 필요합니다.
